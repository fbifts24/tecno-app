Instructivo para incorporar Bootstrap al proyecto

  1. Acceder a https://getbootstrap.comy copiar el comando para instalar el modulo en la app
  2. Dentro de la app abrir la terminal, pegar y ejecutar el comando
  3. En la carpeta node_modules buscar la carpeta bootstrap, desplegar la carpeta dist y luego css
  4. Dentro de css buscar el archivo bootstrap.min.css, clickear con el boton derecho y copiar la ruta relativa
  5. Buscar la clave styles dentro del build en el archivo amgular.jdon, y agregar la ruta copiada (va entre ""), de ser necesario reemplazar las \ por /
  6. Solo en caso de ser necesario incorporar JS: ir a la carpeta js dentro de node_modules/bootstrap/dist y copiar la ruta relativa del archivo bootstrap.bundle.min.js
  7. buscar la clave scripts dentro del build del angular.json y agregar la ruta copiada (igual que antes, va entre "", y reemplazando las \ por / en caso de ser necesario)
